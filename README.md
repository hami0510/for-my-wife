# 💖 이레 안심 가이드

임신 초기부터 출산, 육아(0~24개월)까지 이레 엄마·아빠가 함께 쓰는 **임신·육아 백과사전 웹앱**입니다.
출산 예정일만 입력하면 현재 임신 주차, D-Day, 주차별 가이드가 자동으로 계산됩니다.

> ⚠️ 이 앱의 의학 정보는 참고용이며 진단·처방을 대신하지 않습니다.
> 이상 증상은 산부인과·소아과 전문의와 상담하세요. · 약물 상담: 마더세이프 ☎ 1588-7309

## ✨ 주요 기능

### 사이드바
| 기능 | 설명 |
|---|---|
| 📖 오늘의 말씀 | 날짜별로 31개 성경 구절을 순환해서 표시 |
| 📅 주차·D-Day 계산 | 출산 예정일 입력 → 임신 주차, D-Day, 예정일 표시 (예정일 = LMP + 280일) |
| 🎉 다가오는 기념일 | 다음 마일스톤 2개를 D-Day로 표시 (안정기, 만삭 등) |
| 🌡️ 컨디션 기록 | 엄마 컨디션과 메모를 시트에 저장 |
| 💌 태교 편지함 | 이레에게 쓰는 편지를 시트에 저장 |
| 👶 태동 카운터 | 2시간 내 10회 기준으로 태동 확인 |
| 🔒 태교 편지 보기 | 비밀번호를 입력해야 시트 바로가기가 열림 |

### 메인 탭 (9개)
| 탭 | 내용 |
|---|---|
| 📅 주차별 가이드 | 1~40주 태아 크기·발달, 엄마 변화, 아빠 미션(완료 체크), 주의사항 |
| 🥗 음식 안전 | 카테고리별 음식 ⭕/⚠️/❌ 분류와 검색, 영양제 가이드 |
| 💊 약물 안전 | 해열제·감기약·소화제·항생제 등 안전도 분류와 검색 |
| 🏥 검사·기록 | 시기별 산전 검사 일정, 주치의 질문 노트, 검진 결과 기록장(체중 그래프), 신생아 예방접종 일정 |
| 👶 육아 백과 | 0~24개월 월령별 발달·수유·수면 가이드, 육아 로그(수유·기저귀·수면) |
| 💬 AI 상담 | 현재 주차를 반영한 GPT-4o 챗봇, 사진 질문 지원, 대화 시트 저장 |
| 🚨 응급·진통 | 파수·출혈·태동 감소 등 상황별 행동 가이드, 출산 병원 연락처, 배뭉침(진통) 타이머 |
| 👨‍👩‍👧 휴가·휴직 | 출산전후휴가·배우자 출산휴가·육아휴직 제도 요약과 급여 계산기 (2026년 기준) |
| 📋 준비 도구 | 체중 트래커(BMI 연동), 출산 준비물 체크리스트, 정부 지원 체크, 엄마 마음 체크, 홈 화면 추가 방법 |

## 🛠️ 기술 스택

- **Frontend / App**: [Streamlit](https://streamlit.io)
- **AI 상담**: OpenAI API (`gpt-4o`, 스트리밍·이미지 입력)
- **데이터 저장**: Google Apps Script(웹앱) → Google Sheets
- **배포**: Streamlit Community Cloud

## 🚀 설치 및 실행

### 1. 패키지 설치

`requirements.txt`

```
streamlit>=1.31
openai>=1.0
requests
```

```bash
pip install -r requirements.txt
```

### 2. Secrets 설정

로컬에서는 `.streamlit/secrets.toml` 파일에, Streamlit Cloud에서는 **App Settings → Secrets**에 입력합니다.

```toml
OPENAI_API_KEY = "sk-..."          # AI 상담용 OpenAI API 키
LETTER_PASSWORD = "비밀번호"        # 태교 편지 보기 비밀번호
```

> 🔐 `secrets.toml`은 절대 GitHub에 올리지 마세요. `.gitignore`에 `.streamlit/secrets.toml`을 추가하는 것을 권장합니다.

### 3. 실행

```bash
streamlit run streamlit_app.py
```

## 📊 시트에 저장되는 데이터

`save_to_sheets(type, content, status)` 함수로 Google Sheets에 아래 유형의 기록이 쌓입니다.

| type | 저장 시점 |
|---|---|
| 컨디션 | 사이드바 '기록 전송' |
| 태교편지 | 사이드바 '편지 저장' |
| 아빠미션 | 주차별 아빠 미션 완료 체크 |
| 주치의질문 | 질문 노트 '질문 추가' |
| 검진기록 | 검진 결과 '기록 저장' |
| 육아로그 | 수유·기저귀·수면 버튼 |
| AI상담기록 | AI 상담 '대화 시트에 저장' |
| 체중기록 | 체중 트래커 '시트에 기록' |
| 마음체크 | 마음 체크 '기록 저장' |

> 화면에 보이는 목록(질문 노트, 검진 기록, 육아 로그 등)은 **현재 세션 기준**이라 새로고침하면 초기화됩니다. 누적 기록은 시트에서 확인하세요.

## 🔒 보안 참고

- 앱의 비밀번호 잠금은 **앱 화면의 버튼만 숨깁니다.** 시트 자체를 보호하려면 Google Sheets 공유 설정을 **"제한됨"**으로 바꾸고 가족 계정만 추가하세요.
